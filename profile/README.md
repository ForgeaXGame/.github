### What ForgeAX gives you

- **Rendering** — Materials, lights, shadows, post-processing, and GPU VFX on WebGPU
- **Gameplay** — ECS world, 2D/3D physics (Rapier), animation, input, audio, and network sync
- **Asset pipeline** — Import glTF / FBX / images, or generate assets in TypeScript
- **AI-first debugging** — Query live entities, record / replay render frames, inspect draws and pixels
- **CLI workflow** — Create, run, inspect, and package games with `forgeax` commands

```bash
npx -y @forgeax/game install
```
